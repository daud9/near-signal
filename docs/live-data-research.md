# Live data research and provider decisions

## Selected public live sources

NEAR’s [RPC provider list](https://docs.near.org/api/rpc/providers) identifies FastNear’s `https://free.rpc.fastnear.com` as a public mainnet endpoint with a free tier. The listed free-tier request limit is “Not published”; archival access is paid-only. The app needs only current/finalized reads, not historical archive queries. The [NEAR block/chunk reference](https://docs.near.org/api/rpc/block-chunk) documents `block` by `finality`, `chunk` by block height plus shard ID, and the returned chunk header fields. The [network RPC reference](https://docs.near.org/api/rpc/network) documents status and validator reads.

A browser-origin probe from this environment found the FastNear free endpoint allowed an `OPTIONS` CORS preflight for JSON `POST`, then returned `status` with `chain_id: mainnet`. A live finalized-block verification requested every referenced shard: **10/10 chunks matched the block’s chunk hash, shard ID and inclusion height**, with a complete total of **5 transactions** in that sampled block. The official chunk response schema does not contain a separate `block_hash` field. An initial probe mistakenly required that undocumented field; this was a probe error, not evidence of a chain mismatch. No implementation check was relaxed—the app continues to validate every field in the published response schema and withholds incomplete totals.

The legacy `https://rpc.mainnet.near.org` hostname did not permit browser CORS in the app test and returned HTTP 429 with a deprecation notice during a direct probe on 14 November 2026. The selected FastNear endpoint is therefore both the provider-listed free URL and the one that passed the browser test. Other no-key candidates tried from this environment included `near-rpc.publicnode.com`, `1rpc.io/near` and `near.drpc.org` (403), a Tenderly URL (404), and `rpc.near.gateway.fm` (DNS failure). These are environment-specific results, not proof that the providers are universally unavailable. Do not load-test shared public endpoints.

The dated rebuild generated at **2026-11-14 06:54:44 UTC** received successful responses from all eight connected feeds, with zero failed requests; five candidate sources remained disconnected and were not queried. It contained 31 complete matched market/TVL dates from 14 October through 13 November, finalized block 224,478,873, a full 10-chunk sample counting 1 transaction, and a current validator set of 343 records. CoinGecko reported $3.36 and −2.68% over 24 hours; DefiLlama spot was $3.3600, timestamped about nine seconds later. The browser check at **06:53 UTC** also completed all eight source requests, showed a different complete per-block sample of 3 transactions across 10 chunks, and produced no console, page or failed-request errors. These are dated observations, not guaranteed current values.

## Market and TVL sources

[CoinGecko’s keyless API guidance](https://docs.coingecko.com/docs/keyless-public-api) and [simple-price reference](https://docs.coingecko.com/demo/reference/simple-price) describe timestamped market fields. Its keyless service is intended for testing, open-source and educational use, has a shared dynamic request limit and calls for attribution. The app fetches the current snapshot and [daily market-chart data](https://docs.coingecko.com/demo/reference/coins-id-market-chart) on load or user refresh; it does not poll these endpoints in the background.

[DefiLlama’s NEAR spot endpoint](https://coins.llama.fi/prices/current/coingecko:near) supplies a separately timestamped price check. Its [historical NEAR TVL endpoint](https://api.llama.fi/v2/historicalChainTvl/near) returns dated daily USD snapshots. Its [metric definitions](https://docs.llama.fi/analysts/data-definitions) describe TVL as stock, not flow. The app refreshes spot about every two minutes and TVL about every 30 minutes. Neither source represents net investment or reconciled bridge/Intents flow.

## Why daily user and flow data remain disconnected

- [NearBlocks API plans](https://nearblocks.io/apis) describe a personal-use free plan; its [terms](https://nearblocks.io/terms) require prior written consent for third-party apps and prohibit automated data collection. A successful unauthenticated test did not establish permission for this product. The app makes no NearBlocks requests. Its legacy API docs announced v1/v2 shutdown for 22 November 2026.
- [Pikespeak’s OpenAPI](https://api.pikespeak.ai/openapi.json) includes a daily active-account endpoint, but access is API-key-gated. No key is configured. A provider-reported address count would not establish verified people, retention or organic adoption.
- FastNear’s indexed history endpoints are separate from its public RPC and require an API key. No key or authorized query is configured.
- NEAR’s [BigQuery guide](https://docs.near.org/data-infrastructure/big-query) describes extensive historical tables, but a Google query project and permissions are required; query processing may incur cost. No project, SQL job, cost guard or validated query result is configured.
- The [NEAR Intents Explorer API](https://docs.near-intents.org/integration/distribution-channels/1click-api/explorer/introduction) requires partner JWT access and covers 1Click records, not all Intents or all ecosystem movement. A JWT must not be embedded in browser code.
- [Goldsky’s NEAR offering](https://goldsky.com/chains/near) is an indexing product, not a verified anonymous public stats API. The [Bitquery supported-chain list](https://docs.bitquery.io/docs/blockchain/supported-chains/) did not establish the required NEAR daily-history feed. [NEAR Lake](https://docs.near.org/data-infrastructure/tutorials/running-near-lake/run-near-lake) stopped receiving new blocks on 24 March 2026.
- DefiLlama’s [bridge API documentation](https://api-docs.defillama.com/) marks bridge methods as paid-plan endpoints. Bridge catalogue and volume requests returned a paid-plan response. Adding that endpoint would not by itself resolve direction, coverage or double-counting across both bridge legs.

Therefore daily account cohorts, user retention, daily transaction trends, historic fee series, complete application concentration, reconciled bridge/Intents net flows, multi-epoch validator history and long-run infrastructure history remain unavailable. The product shows these limits and withholds its overall score rather than presenting a proxy as the missing measure.

## Architecture reference review

Fincept Terminal’s repository metadata declares AGPL-3.0 and its LICENSE contains GNU Affero GPL version 3. Its [Python contributor guide](https://github.com/Fincept-Corporation/FinceptTerminal/blob/main/docs/PYTHON_CONTRIBUTOR_GUIDE.md) separates screens, services and data sources and returns structured results; its [architecture guide](https://github.com/Fincept-Corporation/FinceptTerminal/blob/main/docs/ARCHITECTURE.md) keeps network work out of module import. NEAR SIGNAL applies those ideas in its existing JavaScript design: `src/app.js` renders, `src/data.js` owns source adapters/status, `src/analytics.js` contains pure calculations, and imports perform no network requests. No Fincept code, runtime or dependencies were copied.

The repository’s [CoinGecko wrapper](https://github.com/Fincept-Corporation/FinceptTerminal/blob/main/fincept-qt/scripts/coingecko.py) uses the same market endpoints already called by NEAR SIGNAL, adding no new evidence. Its [DefiLlama wrapper](https://github.com/Fincept-Corporation/FinceptTerminal/blob/main/fincept-qt/scripts/defillama_data.py) does not establish complete NEAR-directed net flows. The decision is to keep this project’s smaller JavaScript architecture and avoid AGPL code reuse.
