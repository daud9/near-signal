# DeFi yield and APR sustainability in NEAR

**Scope.** A high APR/APY is not evidence of fraud. The useful question is whether the quoted return is economically funded, liquid enough to exit, and stable enough to survive normal price and utilization changes. Risk impact and source confidence are separate: a weak signal can be economically important but should not produce a high-confidence alert.

## Verified live data surfaces

1. **NEAR canonical RPC (keyless public read).** `POST https://rpc.mainnet.near.org/` with JSON-RPC `block`, `status`, `validators`, or `query`. The `block` response exposes `result.header.height`, `result.header.hash`, `result.header.timestamp`, `result.header.gas_price`, and `result.chunks[]` (`chunk_hash`, `shard_id`, `gas_used`, etc.). `query` with `request_type:"call_function"`, `finality:"final"`, `account_id`, `method_name`, and base64 `args_base64` returns `result.result` as bytes plus `result.block_height`, `result.block_hash`, and `result.logs`; decode the bytes as UTF-8 JSON. This is the dependable basis for reproducible contract-state checks, but the method names and returned schema are contract-specific. [1] [2]

2. **FastNEAR NEAR Data (keyless status is not guaranteed by the docs).** The documentation identifies latest-finalized and block/header routes such as `https://api.fastnear.com/v1/...?` only through the linked NEAR Data API reference, and says NEAR Data serves recent optimistic/finalized blocks and headers. The docs also state that FastNEAR API keys work across APIs and RPC. Treat the connected FastNEAR feed as usable only where the existing integration has already demonstrated a successful response; do not assume every documented route is unauthenticated. [3]

3. **Ref/Rhea pool state through NEAR RPC.** The Ref Finance SDK documents the contract view `get_pools` (wrapped by `getTotalPools`/pool fetch helpers) and pool objects with `id`, `tokenIds`, `supplies` (raw token amounts by token account), `fee`, `shareSupply`, `pool_kind`, and sometimes `tvl`/`token0_ref_price`. These are on-chain state fields, not a protocol-independent APR. The SDK examples show `tvl` and reference price may be undefined, so USD TVL must be computed using independently verified token prices and decimals. [4]

4. **DefiLlama TVL (keyless) and yields (not keyless as of this research date).** `GET https://api.llama.fi/v2/chains` and the free TVL endpoints are documented as public. The API documentation says the old yield routes `/pools`, `/yields/pools`, and related chart routes stopped working on 13 November 2026 and that the replacement `/yields/v1/*` and `/yields/v2/*` routes require the API plan. A live probe on 14 November 2026 returned HTTP 404 for both `https://api.llama.fi/pools` and `https://api.llama.fi/yields/v1/pools`, while `https://api.llama.fi/v2/chains` returned 200. Therefore no current keyless DefiLlama APY history should be assumed. [5] [6]

## How to distinguish sustainable from incentive-dependent yield

**Reward dependence.** For a pool with an advertised gross APR, classify the components as fee/interest yield and emissions yield. A defensible sustainability test is `emissions_share = emissions_APR / gross_APR` over the same interval. Flag **high economic risk** when emissions are the only identified source or when `emissions_share >= 0.80` for two consecutive observations; use **medium risk** at 0.50–0.80. This is a test rule, not a fraud conclusion. Current feeds can observe pool balances and token transfers only if the protocol contract and reward-token accounting methods are known. A free public DefiLlama yield feed is unavailable now; a protocol-specific RPC view or indexed transfer source must be added. **Source confidence: medium** when reward schedules are read from the contract; low when inferred from UI text.

**Fee yield plausibility.** For a DEX pool, estimate `fee_APR = (rolling fee revenue in USD / mean pool TVL in USD) * (365 days / window_days)`. Use a 7-day window and require at least three daily samples. Compare advertised APR with fee_APR plus separately identified emissions. Flag **high impact** if advertised APR exceeds the measurable fee-plus-emission total by more than 50% for two samples, but only if the protocol’s fee accounting is complete. Ref pool state provides `fee`, `supplies`, and `shareSupply`; it does not itself provide fee revenue. Current connected feeds cannot run this end-to-end without swap/fee event extraction. **Source confidence: low to medium** until a protocol fee-event method is verified.

**Borrow utilization and lending yield.** For a lending market, compute `utilization = total_borrows / total_supplied` at each sample; compute a 24-hour change and 7-day median. Flag **high impact** when utilization is `>= 95%` or rises by `>= 20 percentage points` in 24 hours, because withdrawals and liquidations become more sensitive to a run. Flag **medium impact** when utilization is `>= 85%` for 3 consecutive samples. Neither the generic NEAR RPC nor the Rhea guide publishes a universal market method/field schema. This signal lacks a dependable cross-protocol public source now; implement only after verifying the exact market contract view and fields (`total_borrows`, `total_supplied`, rate parameters) for each deployment. **Source confidence: high only after contract-specific schema verification.**

**TVL and exit liquidity.** Use pool `supplies` converted with token decimals and independently sourced prices; for lending use supplied TVL and borrow TVL separately. Flag **high impact** if TVL falls `>= 30%` over 24 hours or `>= 50%` over 7 days, and **medium impact** for `>= 20%` over 7 days. Do not call this manipulation or fraud: it is an exit-liquidity warning. Existing connected DefiLlama chain/protocol TVL can run a coarse protocol/chain-level version, but not reliably identify each NEAR pool. Ref pool state plus CoinGecko prices can run a pool-level version if token decimals and pool IDs are configured. **Source confidence: medium** for raw on-chain balances and lower for USD conversion of thin/illiquid tokens.

**Yield volatility.** Store each observed APR/APY with its timestamp and calculate 7-day median, median absolute deviation (MAD), and maximum one-step change. Flag **medium impact** if the 7-day coefficient of variation exceeds 0.50 or if APR changes by `>= 50%` between adjacent daily samples; flag **high impact** if the advertised yield drops `>= 75%` within 48 hours while TVL is also falling. These rules detect instability, not dishonesty. Current connected feeds cannot run this without a live yield endpoint or contract-derived rate calculation; DefiLlama’s current keyless yield route is unavailable. **Source confidence: low until a reproducible historical rate source exists.**

**Pool age and observation depth.** Define pool age from the first finalized block in which the pool creation/state record is observed, not from a website launch date. Require at least 7 days of observations before issuing volatility or sustainability alerts; label pools younger than 30 days as **high uncertainty**, not high risk. NEAR RPC can provide finalized block heights/timestamps and contract state, but a generic RPC does not index historical contract state or identify pool creation automatically. This can be added with free FastNEAR historical block data or an archive/indexer, but is not runnable from the listed feeds alone. **Source confidence: medium for block time, low for inferred creation time.**

**Borrow-cost coverage.** For leveraged or looping strategies, estimate `net_APR = gross_supply_APR - borrow_APR * leverage - expected_loss_rate - fees`. Flag **high impact** when net_APR is negative at the current observed rate or becomes negative under a 20% adverse-rate stress. This requires the market’s supply rate, borrow rate, and leverage/position data. No dependable generic public NEAR field source was verified; do not fabricate it from APY alone. **Source confidence: high only with contract-specific market fields.**

## Alerting policy

An alert must contain an observed value, timestamp/window, endpoint, decoded fields, formula, and threshold result. Never emit “not yet observed” as an alert. Separate `impact` (economic consequence if true) from `source_confidence` (quality and directness of the evidence). A high APR with deep TVL, sustained fee/interest coverage, moderate utilization, and low volatility may be legitimate; a low APR pool can still be dangerous if liquidity is collapsing or utilization is near exhaustion.

## Limitations

The supplied feeds can verify NEAR chain liveness/finality and can support raw contract reads, token pricing, and coarse TVL. They do not currently provide a universal, keyless NEAR-wide catalog of pool APR components, reward schedules, lending utilization, fee revenue, or pool creation dates. Contract-specific RPC calls are the reproducible free path, but each protocol needs verified account IDs, method names, argument schemas, token decimals, and reward accounting. DefiLlama’s current documentation and live response status specifically rule out treating its yield API as a current keyless dependency.
