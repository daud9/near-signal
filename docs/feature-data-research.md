# Feature data research: liquidity, network activity, and value capture

## Data additions selected

### Liquidity & TVL Context

- **DefiLlama NEAR DEX volume:** `GET https://api.llama.fi/overview/dexs/Near` is a free, keyless chain overview. A live check on 14 November 2026 returned HTTP 200 with wildcard CORS and 1,911 dated `totalDataChart` observations beginning 22 August 2021; the response also included `totalDataChartBreakdown` and rolling totals. Use dated observations for historical charts and compute window sums only when every expected UTC date is present. DEX notional volume is activity context, not deposits, net capital inflow, or pool depth. [DefiLlama volumes API](https://api-docs.defillama.com/) · [live NEAR response](https://api.llama.fi/overview/dexs/Near).
- **DefiLlama aggregate NEAR TVL:** `GET https://api.llama.fi/v2/historicalChainTvl/near` provides daily USD stock observations. Show its longer history directly; do not require CoinGecko dates for a TVL-only chart. TVL can move due to asset prices and adapter coverage and is not a flow. [DefiLlama API](https://api-docs.defillama.com/) · [metric definitions](https://docs.llama.fi/analysts/data-definitions).
- **DefiLlama protocol index/history:** `GET https://api.llama.fi/protocols` exposes reported current chain TVL values; selected `/protocol/{slug}` records provide dated `chainTvls.Near.tvl` history. These are the provider-indexed protocols, not a complete census. Existing history requests remain bounded to the highest-ranked eligible rows and disclose partial coverage. [protocol index](https://api.llama.fi/protocols).
- **DefiLlama NEAR stablecoin circulation:** `GET https://stablecoins.llama.fi/stablecoins?includePrices=true` reports provider-classified peg, quote, current NEAR circulation, and a previous-day circulation field for eligible assets. The endpoint does not supply a provider quote timestamp; circulation is not proof of reserves or redemption. [DefiLlama stablecoins API](https://api-docs.defillama.com/).
- **GeckoTerminal NEAR pool page:** `GET https://api.geckoterminal.com/api/v2/networks/near/pools?page=1` returned HTTP 200 with wildcard CORS and 20 JSON:API pool records. The response includes pair name/address, reserve USD, rolling USD volumes and transaction counts, prices, and time-window price changes. The API is beta, cached for one minute, and limited to approximately 10 requests/minute; request the documented version header and refresh conservatively. Display a page-bounded snapshot, never a chain-wide total. Pool reserves can overlap or be incomplete and differ from DefiLlama chain TVL. [GeckoTerminal API docs](https://api.geckoterminal.com/docs/index.html) · [live NEAR pool page](https://api.geckoterminal.com/api/v2/networks/near/pools?page=1).

### Network Activity & Validators

- **FastNEAR current validator response:** `POST https://free.rpc.fastnear.com` with JSON-RPC `validators` and `params: [null]` returns current and next validator sets, epoch height/start, current proposals, previous-epoch kickouts, slashing flags, per-validator block/chunk/endorsement produced and expected counters, shard assignments/endorsements, and a `validator_reward_paid_prev_epoch` map. A live check returned 355 current records, 353 next records, epoch height 4,970, and 405 proposals; these counts are observations only and must not be hard-coded. Derived ratios require valid non-zero denominators. Stake concentration is only over the RPC-reported validator-account set; current proposals are not active validators. [NEAR RPC provider list](https://docs.near.org/api/rpc/providers) · [FastNEAR current validators](https://docs.fastnear.com/rpc/validators/validators-current) · [validators by epoch](https://docs.fastnear.com/rpc/validators/validators-by-epoch).
- **FastNEAR finalized block + Neardata exact-height sample:** the existing finalized block and validated Neardata requests support gas and transaction totals by shard for one matched block. Do not translate a sampled block into a daily series, people, retention, or adoption. Neardata documents unauthenticated public access with a 180-request/minute/IP limit; this app remains conservative and does not bulk-backfill blocks. [NEAR block/chunk RPC](https://docs.near.org/api/rpc/block-chunk) · [Neardata server](https://mainnet.neardata.xyz/) · [server repository](https://github.com/fastnear/neardata-server).

### Value Capture Lab

- **DefiLlama NEAR fees:** `GET https://api.llama.fi/overview/fees/Near` is a free, keyless overview. A live check returned HTTP 200 with wildcard CORS and dated `totalDataChart` observations beginning 25 January 2024. Plot and sum this as *DefiLlama-reported indexed chain fees*; coverage/methodology are provider-defined, so it is not a reconciled protocol fee ledger or investor revenue. [DefiLlama fees API](https://api-docs.defillama.com/) · [live NEAR response](https://api.llama.fi/overview/fees/Near).
- **Protocol-version-aware fee rule:** official NEAR documentation says contracts received a 30% eligible gas rebate through protocol version 86; from version 87, all transaction fees are burned. Validator rewards are paid from an inflationary budget independently of transaction fees. The RPC `EXPERIMENTAL_protocol_config` can be queried by `block_id`; its `runtime_config.transaction_costs.burnt_gas_reward` parameter records the block-specific rule. A live FastNEAR check returned protocol version 88 with `[0,1]`. Fetch and compare against the observed block version; if the field is missing or mismatched, show it as unavailable. [NEAR protocol-config RPC](https://docs.near.org/api/rpc/protocol) · [NEAR validator economics](https://docs.near.org/protocol/network/validators) · [NEAR gas](https://docs.near.org/concepts/basics/transactions/gas) · [nearcore gas specification](https://near.github.io/nearcore/architecture/how/gas.html) · [HSP-027](https://gov.near.org/t/hsp-027-remove-the-near-developer-gas-rebate/42213).
- **Accounting boundary:** `block gas_used × header gas_price` is an observed block-level execution-gas value, not automatically a signer’s final debit, total fees burned, protocol revenue, or validator income. Prepaid gas can be refunded; transactions and receipts can span blocks; fixed action/receipt costs have different accounting; block aggregate fields do not identify all fee beneficiaries. Keep the value labeled as an estimate/proxy and show the protocol rule separately. Do not infer APY or value capture from it. [NEAR block/chunk RPC](https://docs.near.org/api/rpc/block-chunk) · [NEAR gas RPC](https://docs.near.org/api/rpc/gas) · [NEAR transactions RPC](https://docs.near.org/api/rpc/transactions).

## Source-access guardrails

DefiLlama free routes require no key; the free public API is still subject to availability/rate limits. The retired free yield endpoints are not used: DefiLlama says `/pools` and `/chart/{pool}` shut down on 13 November 2026, while replacement yield routes require an API plan. Do not build against paid token-liquidity/inflow endpoints or authenticated indexers. [DefiLlama API authentication and endpoint catalog](https://api-docs.defillama.com/).

NEAR’s public RPC is free but shared and rate limits are not published for FastNEAR; no load-testing or bulk history crawl is performed. Historical validator queries or full receipt-level fee reconstruction are intentionally out of scope for the static browser app. If a feed fails, goes stale, changes shape, or lacks enough consecutive observations, its metric remains unavailable rather than being interpolated or substituted.
